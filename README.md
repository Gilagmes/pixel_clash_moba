# Pixel Clash Arena

Telegram Mini App — pixel MOBA prototype with 3v3 and 5v5 rooms and WebSocket multiplayer.

## Render

- Build Command: `npm install`
- Start Command: `npm start`
- Root Directory: repository root
- Render supplies `PORT` automatically.

Health check: `/health`

## Security

Do not commit the Telegram bot token. Put `BOT_TOKEN` only in Render Environment Variables.
